# Padaria e Conveniência Bela Vista

## Sobre o projeto

Este projeto consiste no desenvolvimento de um site institucional para a **Padaria e Conveniência Bela Vista**, com o objetivo de apresentar o estabelecimento, disponibilizar informações importantes aos clientes e facilitar o acesso aos seus produtos, serviços e canais de contato.

O site foi desenvolvido como parte de um projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (ADS), utilizando tecnologias fundamentais para o desenvolvimento web.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Maps
- Documentos PDF

## Funcionalidades

- Apresentação institucional do estabelecimento.
- Informações sobre a padaria e seus produtos.
- Horários de funcionamento.
- Disponibilização de cardápios em PDF.
- Localização integrada ao Google Maps.
- Informações de contato.
- Layout responsivo, adaptado para diferentes tamanhos de tela.

## Como executar o projeto

1. Acesse o repositório no GitHub.
2. Faça o download dos arquivos ou clone o repositório.
3. Extraia os arquivos, caso tenha realizado o download.
4. Abra a pasta do projeto.
5. Execute o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para visualizar o site durante o desenvolvimento.
